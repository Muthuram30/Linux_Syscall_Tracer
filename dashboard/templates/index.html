About This Project

Linux System Call Tracer & Process Monitor

An educational operating systems project that demonstrates:

  • System Call Tracing: Using ptrace() to intercept and analyze system calls
  • Process Monitoring: Reading /proc filesystem for process information
  • User/Kernel Mode: Understanding the boundary between userspace and kernel
  • Process Lifecycle: fork(), exec(), wait(), exit()
  • Memory Management: mmap(), brk(), memory allocation
  • File I/O: open(), read(), write(), close()

Key OS Concepts

  • System calls are the interface between user programs and the kernel
  • ptrace() allows one process to observe and control another
  • /proc is a virtual filesystem exposing kernel data structures
  • Processes transition between user mode and kernel mode during syscalls
  • Context switching occurs when the kernel handles system calls

Technology Stack

  • Backend: C (ptrace, /proc, process management)
  • Dashboard: Python Flask + HTML/CSS/JavaScript
  • OS: Linux (Ubuntu)
  • Build: GCC, Make
